v2.1.0 — Dialer

**App renamed to Dialer** (English) / **الهاتف** (Arabic).

### Highlights

- **Clipboard-to-call prompt.** Copy a phone number anywhere on the device and switching back to the dialer offers Call / Add to contact / Cancel.
- **Share-text receiver.** Share any text containing a phone number into the dialer for the same prompt.
- **Picture-in-Picture for active calls.** The call screen shrinks into a floating window when you leave it. Tap to return to full screen; Hang up from the floating action.
- **Ongoing-call notification works.** Mute / Speaker / Hang up buttons now actually fire when tapped (manifest-registered `InCallActionReceiver`). Tap the body to return to the call.
- **Recents collapses per contact.** All calls to or from a contact — across mobile, work, landline — appear as one entry ordered by the most recent call.
- **Smarter dialpad suggestions.** Tolerant of spaces, dashes, parentheses, dots, and country-code variants (last-7-digit suffix scan). Tap a suggestion to place the call directly. Long-press the delete key clears the input.
- **Duplicate scan shows where each contact lives.** Per-contact storage label (Google, SIM, Local, etc.) under each name. Pairs whose contacts live in different accounts are no longer suggested as duplicates.
- **Contact picker matches the main list.** A–Z section headers, collapsible, search-aware — used everywhere the app picks a contact (speed dial, shake target, add-to-existing).
- **"Save as new contact" → "Add to contact".** The Recents row action now routes through the existing Create new / Add to existing chooser instead of jumping straight into a new editor.

Install via the in-app updater (Settings → Check for updates) or download the APK below.
